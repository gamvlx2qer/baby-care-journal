# 总怕冷怎么办呢

> 更新时间：2026-09-15 (UTC+8)

总怕冷怎么办呢

老年人的身体各项机能都下降许多，体温可能会比正常人稍微低一些，即便是在气温比较高的季节，也容易出现全身怕冷的症状。这个时候就应该及时采取措施帮助缓解，以免会因此诱发更严重的疾病。为此小编搜集到了针对于不同部位的防冷措施，大家可以阅读文章来了解一下。

1**女人怕冷是什么原因**

　　月经导致缺铁

　　女性主要因为月经导致铁的损失，应每日摄入18毫克的铁，但是大多数妇女没有达到这个要求，因而怕冷。

　　长期空调冷气

　　女性长期处于冷气房内，禁不住冰淇淋、冰咖啡、蛋糕甜食、南洋水果的诱惑。穿衣服贪清凉，经常无袖上衣加短裤短裙，都容易引起畏冷症。

　　甲状腺素分泌

　　甲状腺素有“生热”的作用，能使人体基础代谢增高，皮肤血液循环加快，增加热量。而甲状腺素分泌不足时，由于产热少，所以怕冷。那些对寒冷耐受力低的人，常有伴有血浆中甲状腺素低的问题。

　　热量释放较少

　　女性因为体内雌激素的含量高，体内的热量容易转化成脂肪储存在皮下。且新陈代谢率较男性低，热量的合成作用大于分解作用，从而使体内热量释放较少。加上女性一般不太喜欢活动，热量的产生就会更少。运动量不足，往往会造成全身或局部循环不良，导致全身发冷，特别是手、足等末稍部位更觉冷。

　　另外，荷尔蒙的分泌失调、新陈代谢机能衰退、自律神经运作迟缓、血管分布较少的手足及腰部血液循环不良等也会导致畏冷症。

2**总怕冷怎么办呢**

　　1、防肺寒：喝热粥散寒。

       风寒感冒在冬季里可以说是最常见的毛病了。对于一些症状较轻的患者，可以选用一些辛温解表以及宣肺散寒的食材来应对，效果不错哦。服用过后建议上床盖好被子，感到微热有一些出小汗为宜。每天早晨和晚上各1次，连服2天效果才好。

　　2、防腰寒：双手搓腰暖肾阳。

　　双手搓腰有助于疏通带脉、强壮腰脊和固精益肾。腰部为“带脉”(环绕腰部的经脉)所行之所，特别是脊椎两旁的后腰是肾脏所在位置。肾喜温恶寒，常按摩能温煦肾阳、畅达气血。具体的做法是：两手对搓发热后，紧按腰眼处，稍停片刻，然后用力向下搓到尾椎骨(长强穴)。每次做50—100遍，每天早晚各做一次。

　　3、防鼻寒：晨起冷水搓鼻。

　　立冬之后“凉燥”更明显，鼻炎成了许多老人的大麻烦。不妨以寒制寒!每天早上或者外出之前用冷水搓搓自己的鼻翼。每天早晚用冷水洗鼻有利于增强鼻黏膜的免疫力，是防治鼻炎的不错办法。用冷水洗鼻子时，顺便揉搓鼻翼可改善鼻黏膜的血液循环，有助缓解鼻塞、打喷嚏等过敏性鼻炎症状。

3**畏寒怕冷护好五个部位**

　　1、头部

　　头为一身之主宰，诸阳所会，百脉相通，一旦受到寒邪侵袭，易引发感冒、鼻炎、头痛、牙痛、三叉神经痛等。头部还是最不善于留住热量的部位。研究发现，静止状态不戴帽子的人，在气温15℃时，头部散失的热量占人体总热量的30%，气温4℃时，占60%。所以，天越冷越要给头部保暖，冬季外出一定要戴帽子，最好是能盖住前额的。头部出汗后不要立刻摘下帽子，应先到室内慢慢消汗，避免冷风直吹。此外，每天清晨梳头百余次，使头皮微热，有利于头部经络气血通畅，促进诸阳上升，气血不衰。

　　2、鼻子

　　鼻子也经常裸露在外，如果鼻黏膜接触冷空气，黏液分泌会减少，毛细血管会变脆，鼻子的“屏风”作用就变差，从而导致病菌进入肺内，增加呼吸道感染的几率。外出时戴个纯棉口罩，但最好不要用围巾遮挡，以防上面的细菌或织物纤维进入鼻腔。天冷时，可每天按摩鼻翼，两手拇指外侧相互搓热后，沿鼻梁、鼻翼上下按摩30下。早起前、晚睡前各做1次，可增强鼻部血液循环，提高耐寒能力。

　　3、双脚

　　脚是全身最怕冷的部位，“脚冷则全身冷”。肾和脾胃的经脉都起源于脚，但由于双脚距离心脏最远，血液流经的“路程”最长，血液供应往往不足。自身热能不够，就要求助“外援”，最好的办法是每天用热水泡脚，促进周身血液循环，使全身都暖和起来。每次泡脚20分钟，水温42℃左右最佳，同时可按摩脚掌的涌泉穴，起到调理脏腑、舒通经络的作用。鞋袜最好保暖透气、吸湿性好。

　　4、腰部

　　腰部第二怕冷，它是肾之腑，肾喜温恶寒，一旦它觉得冷就会立刻“闹情绪”，男性会腰膝酸软，阳痿早泄，女性则容易月经紊乱、痛经等。因此，无论男女天冷时一定要穿中长外衣，不要让腰部裸露。平时可用双手搓腰：两手对搓发热后，紧按腰眼处(位于第三腰椎棘突下旁开3.5寸凹陷处)，每天早晚各一次，每次做50～100遍，能温煦肾阳、畅达气血。

　　5、耳朵

　　耳朵体积小，接触空气的面积大，热量很容易散发。外加耳朵皮肤薄，耳廓缺少皮下脂肪的保护，极易长冻疮。因此外出一定要给它们“穿上”保暖外衣，可以戴上耳包，或用宽大的帽子、围巾遮住耳朵。从室外进入温暖的室内，可以迅速用手搓一下耳朵，让其快速回暖。坚持每天早、中、晚按摩揉搓耳廓，每次约5～10分钟。

4**怕冷怎么办小方法让你过暖冬**

　　早卧迟起

　　大雪时节，万物潜藏，养生也要顺应自然规律，并要收敛神气，起居调养宜早眠晚起。早晚温差悬殊，早睡以养阳气，迟起以固阴精。

　　寒头暖足

　　马王堆汉墓出土的《脉法》中写道：“圣人寒头暖足，治病者取有余而益不足也。”头为诸阳之会，适当寒冷有助于保持大脑清醒。

　　不要稍有降温就马上戴帽子、包围巾，这样反而容易上火、感冒。寒从脚起，由于脚离心脏最远，热量到达较慢，是阴气聚集之处，最易受到寒邪侵袭，因此需要注意保暖。

　　冬不食肾

　　《修真秘诀》曾记载“冬不食肾”。《金匮要略》也提到：“冬三月，勿食猪羊等肾。” 意思是冬季肾水当令，过食损伤心气。

　　鸡鸣沐浴

　　《运化玄枢》记载大雪时节宜“鸡初鸣时沐浴，令人长寿”。意思是讲早上清洁身体，有利于阳气升腾。入夜阳气收敛，阴寒渐盛，不宜洗浴。

5**教你有效赶走寒冷的办法**

　　1、分析原因

　　引起机体怕冷的原因有许多，中医讲的气虚、血虚都会引起机体怕寒;贫血者因为血红蛋白不足，血液携氧能力下降，导致机体的能量代谢发生障碍，产热不足引起怕冷;体内某些激素的降低，如：雌激素、甲状腺激素的不足，均可以引起机体怕冷，因此要针对原因来采取措施是最根本的办法。

　　2、做好保暖工作

　　身体怕冷的人要注意给自己的身体保暖。尤其要做好四肢末梢部位的保暖，比如腿部、手、脚等部位的保暖。脚要穿棉袜子，不要让腿脚受冷。秋冬季的时候，注意不要穿那种露脚后跟的拖鞋，要穿有后跟包饶的拖鞋，以免自己脚后跟受凉。

　　3、经常参加体育锻炼

　　怕冷的人群要多参加各类体育锻炼活动，每周要坚持三天到五天的锻炼。这是因为锻炼不仅能活络全身的每个关节，还可以促进人体的血液循环，能增加肺活量，从而促进肠胃蠕动，预防便秘。

　　4、通过饮食来改善

　　经常怕冷的人可以注意一下自己的饮食，通过饮食来改善。羊肉富含蛋白质、丰富的B族维生素以及一些铁、锌等离子。在寒冬季节可以益气补虚，促进血液循环，从而达到御寒的能力。喝一碗羊肉汤立马就能感觉到全是暖意浓浓的。当然也可以经常的食用薏米粥。

　　5、生活规律，保证睡眠

　　特别怕冷的人要注意保持良好的生活规律，不要让自己经常处于疲劳、精神紧张的状态，这是因为人在这样的不良状态中，免疫力会容易下降。要保证每天八小时的睡眠时间，不能熬夜，熬夜也是伤身体的。

　　6、不要久坐不动

　　在发觉自己有冷意的时候，不要久坐不动。不妨站起来，做一些运动。比如踢毽子，单脚踢上20几个，保证你全身热乎乎的，踢毽子不仅可以让自己暖和，还可以让自己的大脑动起来，眼睛也随着毽子的上下来回的转动起来起来。

　　7、温水浸泡

　　在发觉自己怕冷的时候，可以用热水浸泡。比如经常的用温水泡手和泡脚。温水可以使自己的血管扩张，让自己的血液循环加速，温水本身也起到了一个保暖的作用。
